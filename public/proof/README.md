# 公开交易证据

[settlement.json](settlement.json) 是当前主案例 Group 11 的精简历史证据索引，保留创建、初始筹款、第五人加入和一位原成员领取差价的交易标识及当时读取的金额。

这不是把全部调试产物发布出来：没有录屏时间轴、截图、失败日志、钱包私钥、浏览器存储或代理会话。

## 如何独立核对

先确认 `chainId`、业务合约及固定测试 token 身份，再用对应网络的 RPC 或区块浏览器查询每笔交易回执。检查成功状态、目标合约、调用方法、事件的活动编号和原付款地址；金额按六位精度解释。

`created` 对应活动创建，`initialFunding` 的四笔加入各为 50 FJUSD，`fifthJoin` 为第五人支付 40，`claim` 为原成员领取 10。钱包余额数字是当时保存的快照，不是永久实时余额；最新结果需重新读取。当前应用公开收据提供额外的只读核对入口。

文件名不表示该活动已经执行 `finalize` 或组织者已经提取本金。这里证明的是一次加入与差价领取；测试账户不是客户，测试币没有价值，链上资金记录不担保线下服务。

原始公开记录的来源链接保留在 JSON 的 `sources` 中。原始记录中的历史界面超时不改写为成功；精简索引仅保留已核对的交易结果。测试网重置或节点历史数据不可用时，应明确说明核查限制。
